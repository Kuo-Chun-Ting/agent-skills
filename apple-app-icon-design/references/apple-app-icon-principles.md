# Apple App Icon 原則

- 圖示需獨特、容易記憶，並能讓人一眼辨識。
- 使用少量形狀表達一個簡單的核心概念。
- 優先使用簡單的純色或漸層背景。
- 優先使用插畫，不使用照片、螢幕截圖或仿製的 UI。
- 提交正方形原始圖稿；由 macOS 與 iOS 套用各自的遮罩。
- 目標流程支援 Icon Composer 時，準備分層的 SVG 或 PNG 圖稿。
- 預覽目標作業系統與平台要求的所有外觀模式。
- 在 16、32 與 64 像素下，確認輪廓、必要開口、重疊關係與對比仍然清楚。
- 小尺寸預覽失敗時，簡化主圖稿；不要另外設計無關的縮圖。
